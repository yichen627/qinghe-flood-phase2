# 黄金数据来源与纪律

原始CSV来自桌面青河学生版v2，虚拟教学数据。data/golden/event*_result.json原样来自一期首次冻结后的模拟与检验结果；每个文件包含该场state0、40个时段Q和指标。它们是回归基线，不是教师无噪声真值。

参数冻结摘要：ed06ce63e886466e33c6a96f017dedbd17710b9a9420c389f7aca09255f2f89a。二期不重新率定。event1–3曾用于率定，event4在一期冻结后检验过，二期固定回归不得再称新盲测。

质量警告：六站泰森复算与原面雨量有少量舍入/生成差异，复算值进入模型；不自动修改原CSV。data/invalid包含课程提供的缺测、负值、乱序和正常样本。

每场初态必须读取自己的记录，不能共享，也不能用前一场终态接续。当前seed采用一期结果中的专属state0，内容与events_index对应。
