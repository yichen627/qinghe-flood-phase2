# 预报工作台使用说明

版本1.1.0。启动Docker后打开 http://localhost:8000/ ，首页是本地业务工作台。/docs仅用于接口开发和调试。前端使用同源HTML/CSS/JavaScript与SVG曲线，不依赖CDN，不需要另开前端服务或构建Node镜像。

## 连接身份

首次进入弹出连接窗口，教学环境可点击预报员、值班长或管理员，再点击连接。自定义.env密钥时需手动填写对应密钥。身份由/workbench/session服务端验证，浏览器不能自行声明角色。密钥仅放当前页面内存，刷新需重新连接。

## 预报操作

1. 右上角导入洪水数据，选择课程样本会同时载入该场CSV和专属初态。上传外部CSV时必须填写自身初态JSON，不自动套用其他场次。
2. 入库执行质控。ERROR记录会留档但禁止起报，工作台显示具体原始行号、字段与问题。面雨量WARNING可查看，不掩盖。
3. 右侧选择已通过质控的数据及方案，点击开始预报。提交真实持久任务，排队和计算状态自动刷新。
4. 成功后显示实测蓝线、模拟橙线、模拟洪峰、DC和RMSE。鼠标在图上移动可查看逐时段流量；可下载原服务生成的PNG。
5. 点击任务查看详情，可核对输入初态、参数与模型摘要，下载误差分析，或使用原快照回放。

## 签发和治理

成功任务点击生成产品草稿。预报员无法复核、签发或发布，左下角身份入口切换值班长，依次复核填写意见、签发和发布。服务端继续执行角色与状态门禁，不能靠前端按钮绕过；签发后可导出JSON。

模型与方案页支持查看参数、新增不可变参数集和绑定方案、激活、灰度、归档和回滚。需管理员身份，未部署算法不可使用；归档活动方案会由服务端拒绝。

调度与通知页支持创建和暂停/启用起报计划，查看质控告警、本地值班通知及确认告警。定时起报不自动签发产品。审计页供值班长和管理员查看最新操作详情。

数据及任务最多加载最近100条，任务列表区域滚动并提供状态筛选；更早记录可通过分页API读取。工作台每5秒刷新，打开表单时暂停刷新；多种手机与桌面布局共享同一服务。浏览器中的角色切换是教学工作流，不是生产级用户管理。

## 验证

pytest共35项通过，新增工作台壳资源、身份验证、示例权限、路径白名单和四场专属初态检查。

安装Node22以上后可独立运行真实浏览器验收（Node只用于开发测试，部署时不需要）：

```powershell
npm ci
npx playwright install chromium
npm run test:browser
```

本机也可设置BROWSER_CHANNEL=msedge使用已装Edge；CI安装Chromium并自动执行。测试通过页面导入样本、绑定新任务ID等待真实完成、查看曲线、创建产品、验证预报员禁止签发、切换值班长复核签发发布、查看方案审计，以及390px手机页面无横向溢出。原始证据与截图见evidence/workbench目录，JUnit见evidence/workbench-junit.xml。
