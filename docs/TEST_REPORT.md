## 覆盖范围

1. 四场从事件导入到模型HTTP处理、结果/指标和PNG的接口回归，各场独立初态。
2. 缺测、负值、乱序数据保留原文和逐行ERROR，预测返回409；NaN输入也被拦截。
3. 面雨量差异WARNING不阻断；重复导入不覆盖，分页边界有效。
4. 无Q实测仍可预报；部分观测缺测只计算有效时段DC/RMSE，不压缩峰时索引。
5. 缺初态、超容量、匿名访问、非法雨量、未知事件和模型版本冲突均拦截。
6. 模型HTTP超时转FAILED，不能获取伪成功图；租约失效保留失败记录；终态不能覆盖。
7. 原子领取同一任务一次，数据库重开仍能读取完整快照；模型请求不含实测Q。
8. 两服务运行时OpenAPI与版本化JSON完全一致。
